首个公开版本：面向终端、SSH 和 Agent 的纯 HTTP 小红书 CLI。

- 短信／终端二维码登录、跨进程保持登录态和独立 profile。
- 搜索、帖子详情、用户发布／喜欢／收藏列表，按当前账号可见权限查询。
- 图片、视频和 Live Photo 下载；默认选择可获得的最优画质。
- 视频有限次数补全候选，标准编码筛选，文件头媒体信息、SHA-256 校验和可恢复下载。
- 终端进度条、速度和 ETA；JSON／JSONL stdout 与 stderr 进度分离。
- TOML、环境变量和命令行参数，完整帮助、Schema 与随包 Agent Skill。

下载对应平台附件并解压即可运行，无需安装 Node.js 或 Bun。Windows 使用 `xhs-dl.exe -H`，macOS／Linux 使用 `./xhs-dl -H`。附件内含使用说明、Skill 和第三方许可；外层 SHA256SUMS 校验压缩包，内层 SHA256SUMS 校验可执行文件。

本次提供 macOS、Windows、Linux glibc 与 musl 的 x64／ARM64 共八种产物。macOS 两种架构、Windows x64 和 Linux x64 在对应 CI 主机上运行测试；其它四种目标通过交叉编译检查。
