# 实施 Roadmap 与验收证据

完整契约见 [架构方案](architecture-plan.md) 和 [用户模块规格](user-content-spec.md)。此清单保留全部核心功能范围；验证事实与实现状态分别记录。

## 核心实现

- [x] TypeScript / PNPM CLI，纯 HTTP 本地签名，无浏览器、外部签名服务或常驻进程。
- [x] 终端/分步短信与扫码登录、Cookie 显式导入、profile 隔离、状态恢复、当前用户与退出。
- [x] 本人/指定用户资料，发布、喜欢、收藏列表，权限观察与拒绝错误。
- [x] 完整/短分享链接、分享文本、ID 与访问参数，API 详情与静态 HTML 回退。
- [x] 图集、所有已识别视频编码档位和备用地址、Live Photo 图片/视频配对归一化。
- [x] 关键词搜索、类型/排序、分页预算、页中截断恢复、游标账号/目标/筛选绑定。
- [x] 下载规划、字段和时间模板、创建目录、安全路径、文件名碰撞策略。
- [x] 流式下载、受控并发、聚合限速、有限重试、备用 CDN、地址过期后刷新详情。
- [x] 基于验证器的断点恢复、文件头校验、大小与 SHA-256 归档去重、固定请求质量口径。
- [x] 多链接/文件/stdin 输入，用户来源直接下载，来源关系、清单、正文与脱敏元数据。
- [x] 完整 TOML/环境/flags 配置覆盖、布尔 false、路径基准、来源追踪和诊断。
- [x] JSON/JSONL、部分失败与退出码、Schema、完整帮助、配套 Skill 和生成式命令参考。
- [x] lint/typecheck/回归测试/构建、配置与媒体集成测试、打包安装检查、跨平台 CI 配置。

## 当前环境实测

日期：2026-11-17，macOS arm64，Node.js 22.22.2。账号数据和原始内容不写入本文件。

| 场景 | 观察与证据 |
| --- | --- |
| 用户实际短信登录 | 保存的挑战为 sms/authenticated；独立 auth status --check 与 me get 均返回同一有效账号 |
| 会话跨进程 | CLI 重启后多次获取本人和其它用户内容，未重新登录 |
| 本人发布/喜欢/收藏 | 发布明确为空且已穷尽；喜欢/收藏取得非空列表和下一页 |
| 指定用户 | 资料、发布、收藏返回正常结果；一个喜欢列表明确为空 |
| 第二页 | 本人喜欢/收藏、指定用户发布在 page-size=5 时取到6条；搜索从第一页20条继续到第21条，合计取回40个卡片 |
| 页内恢复 | 既有收藏 cursor 再取2条，fetched=0，先消费已缓存页内卡片 |
| 搜索类型/排序 | 图文筛选、视频筛选、latest/likes 参数均取得对应结果 |
| 权限 | 另一个用户收藏返回 LIST_PRIVATE / 11，没有伪装成空成功 |
| 详情 | video、三张图集、带三组实况配对的图文详情均解析成功 |
| 真实视频下载 | 传输成功；复跑同一请求策略 verified archive 后跳过，无重复下载 |
| 真实图集下载 | 一篇三张图片的图集完整落盘 |
| 真实实况下载 | 三张图片及三段伴随视频配对完成 |
| 产物 | 共检查11个真实媒体（5视频、6图片），ffprobe均识别有效图像/视频流 |

实测时发现同一帖子不同请求的最高档位会变化，因此 best 归档按请求策略匹配，记录实际质量；新增回归确保平台后续给出更高候选时默认仍幂等跳过。

## 自动验证

- `pnpm check`：ESLint、TypeScript strict、Vitest、生产构建，均通过。
- 当前共54项测试：在同一台 macOS arm64 上分别用 Node.js 22.22.2、24.22.3、26.13.1 运行，三组全部通过；这不等于其它操作系统已实测。
- `pnpm format:check`：代码风格。
- `pnpm docs:check`：命令参考与 CLI registry 一致。
- 合成测试覆盖三档签名向量、真实加密原语、登录状态机、账号隔离、HTTP Cookie/重定向/超时、Schema/错误、静态状态拒绝可执行表达式、分页丢页/去重/权限变化、模板/符号链接、断流/206/ETag变化、错误页、归档与冲突策略、限速和输入超时。
- v0.2.0 安装包在独立临时目录安装：安装后的 CLI 验证真实身份、导出13类 Schema、输出2条搜索 JSONL item 与 summary、从 NoteRef JSONL 输入生成2项下载预演，确认预演不创建媒体目录。
- 最后补充并修正 Netscape Cookie 导入保留 HttpOnly 的回归；凭证仍只读取显式文件。

## 验证边界

以下没有被其它场景的成功替代：

- QR 创建和跨进程轮询已实测；手机确认后的 QR 最终登录分支有本地集成覆盖，但本次真人使用短信登录，QR 最终确认尚未真人实测。
- 断点/限速/异常 CDN 等通过可控本地 HTTP 服务验证，没有人为中断生产平台制造异常。
- 私密收藏已有真实样例；私密喜欢和公开喜欢的其它账号组合仍主要依赖合成权限测试，不声称穷尽所有平台隐私配置。
- GitHub CI 已配置 macOS/Linux/Windows × Node22/24/26，远程矩阵状态以对应提交的 GitHub Actions 结果为准；不能把本机结果当作其它平台已验收。
- 平台内部协议可能变化；capabilities 中 live_verified 仅指此处注明的当前环境实测。
